# NexusAI v15.0

## Added
- Claude-inspired mobile workspace navigation: Chat, Projects, Code and Artifacts.
- Dedicated Code workspace with AI code generation and static validation. Code is not executed.
- Artifacts library aggregating saved website projects and generated images.
- Configurable API-Sports Cricket live fixtures/scores provider with source and fetch timestamps.

## Improved
- Projects workspace label and navigation.
- Mobile layout reserves space for the bottom workspace bar.
- Live cricket card renders real provider results and clear configuration errors.

## Limitations
- Cricket requires a valid API-Sports key and provider plan.
- Static validation is implemented only for JavaScript, JSON, CSS and basic HTML. TypeScript, Python and SQL report that validation is unavailable.
- No source code is executed by the Code workspace.
- No live model, paid API, provider key, or end-to-end production test is claimed.
